Hytale Server Plugin

Companions that actually talk back.

Bud Plugin adds LLM-powered NPC companions to your Hytale server. They follow you, fight beside you, remember what happened, and — new as of 2.0 — can be sent off to farm, log, or mine on their own.

What this is

A companion system, not a chatbot bolted onto an NPC

Each Bud is a real Hytale NPC with its own role, weapon, mood, and memory. When an LLM is configured, their reactions are generated live; when it isn't, they fall back to hand-written dialogue for the same events — the mod is fully playable either way, the LLM is what makes it come alive.

Three companions

Veri, Gronkh and Keyleth — each with a distinct personality, weapon and now a dedicated worker role.

Reacts to almost everything

Combat, block breaks, crafting, item pickups, weather, new zones, your chat, even your status effects.

Remembers you

A decaying, priority-ranked memory store per Bud, plus a small set of permanent "legendary" memories.

Features

What your Buds actually do

🗡️

Dynamic modes

Toggle each Bud between Defensive (fights alongside you), Passive (follows), and Sitting (stays put).

💬

Context-aware reactions

Combat, block placement/breaking, item pickups, crafting, new-zone discovery, weather changes and direct chat mentions all trigger in-character dialogue.

🎭

Mood & favorite day

Moods shift over time and color dialogue; each Bud also has a favorite day of the week they get overmotivated on.

🧠

Memory system

Decaying, priority-ranked memories per player and per Bud, plus a small set of permanently retained "legendary" memories.

🤝

Bud-to-Bud interaction

Buds react to each other's mood changes, spawns and state changes, and can build shared "legendary" memories with one another.

❤️‍🩹

Player state reactions

Buds notice and comment on your status effects — poisoned, regenerating health, and more.

🌾

Worker Mode

New in 2.0: assign a Bud to a Workstation and it farms, logs, or mines the surrounding field on its own. See the dedicated section below.

🎴

Bud Cards

Summon and dismiss companions with a craftable item instead of chat commands — left-click to summon, right-click to dismiss.

🔌

Works without an LLM

Every reaction has a hand-written fallback line. The mod is fully playable with zero LLM configured — the AI layer is what elevates it, not what it depends on.

New in 2.0

Send your Bud to work

Craft a Workstation, bind a Bud to it with a card, and keep it fed with fuel — from there it scans the surrounding field itself and works it autonomously, resting when there's nothing left to do or the fuel runs out.

Farming

Keyleth

till → plant → water → fertilize → harvest

Lumbering

Gronkh

Mining

Veri

Digs holes that grow into minable stone over time, and works ore-bearing main nodes for a steady yield.

dig → wait → mine
Did you know? Trees have real root systems — some species need several blocks of clear soil beneath a sapling to finish growing. Gronkh now digs and refills that space with dirt before tilling. See the tree roots guide for the full explanation and per-species tuning table.

No commands needed

Summon with a card, not a slash command

Each companion has its own craftable Bud Card from the Arcane Workbench, plus a roster card that spawns or despawns every default Bud at once.

  • Left-click (Primary) — summon the matching Bud next to you; respawns it if already present.
  • Right-click (Secondary) — dismiss that Bud again.
  • Carry all three cards to freely mix and match your active companions.

Getting started

Running it locally

  1. Clone the repo, then run .\gradlew decompileServer once to prepare IDE sources.
  2. Build with .\gradlew build — this also runs the JUnit suite.
  3. Launch a local server with .\gradlew runServer.
  4. In-game, log in with /auth login device.
  5. Persist the login with /auth persistence Encrypted so you don't have to repeat step 4 every run.

The plugin works out of the box without any LLM configured — add an LLM.json endpoint later to switch fallback dialogue on for real generated responses.
